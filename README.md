# 广东阿海法电气官网（演示前端）

东莞横沥高低压成套开关设备制造商的双语营销站。这一版只做可给客户看的前端：夹具文案、中英路径、询盘表单的页面回执。没有后台、数据库、邮件或登录。

视觉方向是「深蓝工程权威」：主色 `#0A1E38`，切角面板，工程网格。Logo 用 AHIFA 字标，不另做图形标志。

## 页面

- `/zh` 与 `/en`：首页
- `/products`：产品列表（电压、应用、系列筛选，分页）
- `/products/[slug]`：产品详情（含光伏并网柜 `ah-pv400`、箱变 `ybw-12`）
- `/solutions` 与详情：五个行业方案
- `/cases` 与详情：典型配置，东南亚在前
- `/support`：资料目录、质保、常见问题
- `/about`：公司、工厂、设计依据、历程
- `/news` 与文章
- `/contact`：询盘表单（仅浏览器内成功回执）
- `/privacy`、`/terms`
- 品牌化 404

默认语言是中文。语言切换保持当前路径，只改 `/zh` 与 `/en`。localhost 上两种语言都可以直接打开，不按域名锁定。

## 本地运行

```bash
pnpm install
pnpm dev
```

开发服务器监听 `0.0.0.0:43123`。浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)，会进入 `/zh`。

```bash
pnpm build
```

`pnpm build` 写出静态站点到 `out/`（`output: 'export'`，目录带尾斜杠）。用 nginx 把站点根指到这个目录即可，例如 `root /var/www/ahifa/out;`。`out/index.html` 会把 `/` 送到中文首页 `/zh/`，英文首页在 `/en/`。静态导出不跑 Next 服务，也不使用 middleware。
